# WaterWatch — Full-Stack Development & cPanel Migration

**PRP370S — Project Presentation III | Marco Julian Human**

WaterWatch is a water-monitoring project intended to help households and body corporates better understand water use, flag possible leaks, and estimate monthly costs using City tariff tiers.

## Project links

- **Live application:** [Open WaterWatch](https://witty-platinum-panda.92-205-106-102.cpanel.site/waterwatch/)

- **Portfolio home:** [Return to the portfolio](../../README.md)

## My contribution

My contribution included Node.js and MySQL backend development, project writing/editing and documentation. I also carried out the cPanel migration, including the application and database, helping move WaterWatch from development into its deployed hosting environment.

## Technologies and work areas

- **Frontend:** React and Vite
- **Backend:** Node.js and Express
- **Database:** MySQL
- **Hosting / deployment:** cPanel
- **Project workflow:** Agile artefacts managed and tracked with Trello
